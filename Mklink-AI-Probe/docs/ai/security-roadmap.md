# 芯片加锁与解锁：长期维护任务

状态：长期进行，不作为单个版本必须穷尽的任务，也不自动启动无人值守硬件测试。

## 支持原则

- 按选项字节布局、保护机制和容量组验证代表芯片，不逐个验证完整订货号；同系列
  若存在不同保护架构，不能仅凭系列名直接开放。
- CLI、MCP、在线 GUI 共用安全能力与执行后端；脱机使用上位机生成的 FLM/CFG，
  固件保持通用。脱机支持是在线能力与探针执行器能力的交集，不冒称两者完全一致。
- 型号、芯片 ID、容量、选项范围及 FLM 哈希均须匹配。不支持或证据不足时置灰。
- 只支持可逆读保护，禁止 RDP2；勾选时确认风险。解锁永久擦除全部 Flash，
  先备份并确认可恢复；每次硬件测试重新核对供电电压。
- 默认断电 3 秒；脱机残压门限 800mV。1.8V/3.3V/5V 是供电选项，
  不是所有目标都支持这三个电压。3.3V 之外须明确目标板耐压再验证。

## 当前基线

以下是代表板证据，不代表整个系列所有容量或探针组合均已验证；实际开放范围
以 `mklink/cmsis_dap/security.py` 和 `mklink/offline_security.py` 为准。

| 架构/代表板 | 在线 | 脱机 | 后续重点 |
| --- | --- | --- | --- |
| STM32F1 / F103RE | 保护、擦除解锁、恢复通过 | V3、V4 闭环通过 | 同架构型号按 ID/容量生成配置 |
| STM32F4 / F413VG | 通过 | 尚未开放 | 选项执行器与恢复验证 |
| STM32G4 / G474RE | 通过 | V3 有验证；V4 未开放 | V4 代表板及锁后独立启动 |
| STM32H7 / H743II | 通过 | 尚未开放 | 多 bank/选项布局与断电恢复 |
| STM32L0 / L010F4 | 通过 | 尚未开放 | 小容量目标选项执行器 |
| GD32F303xE / F303CE | 普通暂停闭环通过 | V3 闭环通过；V4 配置可用，尚无本轮实测 | 锁后无调试独立运行、V4 代表板 |
| PY32F030K28T6 | 有历史成功证据，近期重连异常未关闭 | V3 有历史证据；V4 未开放 | 优先复测加锁后解锁及 ERASE_SECTOR 异常 |

## 每次扩展的完成标准

1. 取得官方依据，核对 ID、容量、选项布局、保留字段和可逆保护值。
2. 先读取备份；加锁后确认保护生效，解锁后独立确认全片空白。
3. 恢复原镜像并全片比对，确认程序启动；锁后独立运行须另有不依赖 SWD 的证据。
4. 覆盖错误型号、错误算法、选项不一致、超时和断电异常的拒绝路径。
5. 同步能力接口、GUI 提示、CLI/MCP 与脱机配置测试，记录代表板/探针组合。
6. 只更新结论和证据链接，不把逐次拔插、刷固件、重试过程写进常驻交接。

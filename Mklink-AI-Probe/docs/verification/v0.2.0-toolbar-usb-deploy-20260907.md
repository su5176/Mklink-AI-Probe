# 在线烧录工具栏与 U 盘复用验证

源码：`6a5c5265fe796eb672b4690d7e388cd40fc9afb8`，包含前置工具栏修复 `1a614fb`。
本轮仅开发分支候选，未合并 master 或正式发布；安装包交用户手动安装。

## 问题与修改

- Web/桌面在线烧录移除“文件路径”入口，保留常规选择、拖拽和现有文件跟踪。工具栏可换行、按钮文字不竖排，补中文字体回退及表单字体继承。
- 实际后端日志显示：选择 U 盘 FLM 后部署，删除同名目标文件发生 Windows 文件占用错误。部署现对暂存内容逐块比较，相同内容直接复用，不删除、不重写；返回文件清单仍包含复用文件。内容有变化时保留原有替换和回滚流程。
- 文件操作错误转换为带文件名的业务错误。界面始终显示错误详情，并对 U 盘写入失败、命令串口连接失败给出操作提示。
- 旧桌面触发接口实际返回 `Unable to connect to MKLink CDC port`：当时 Web 服务已连接命令口，桌面未连接。旧界面隐藏了未分类错误。释放 Web 连接后，新 Web/桌面分别触发成功；没有取消串口互斥或强制抢占其他客户端。

| GUI 全量 | 64 文件，682 项通过 |

| 桌面真机 | 实际 Tauri 候选，选择 STM32F103RE 的已安装 Keil 算法，添加同两份 U 盘 HEX，点击部署与触发，同样成功 |
| 桌面路径 API | 独立 sidecar 接收 FLM/两份 HEX 的原 U 盘 `source_path`，部署成功 |
| 原 U 盘文件 | 上述三份文件的 SHA-256 和修改时间不变，确认直接复用；测试前备份保留，临时测试脚本移回报告目录 |
| 目标运行与连接释放 | 烧录后 UART 读到递增的测试输出；命令口可再次独占打开，UART 读完关闭。Web 保持未连接 |
| 桌面生命周期 | 独立 sidecar、无 Python 回退，正常关闭候选后进程和独立端口释放 |

真机为当前 V4 + STM32F103RE；沿用现有测试工程产物，应用与启动程序均已事先核对 U 盘/本地文件一致。本轮未改编译产物、未全片擦除、未加锁/解锁、未切换供电电压、未更新探针固件。

GUI 自动重载验证使用后端可访问的已保存路径；不将普通浏览器 File 上传快照宣称为可持续监控。桌面 FLM 原生文件对话框未在本轮自动化操作，分别验证了实际桌面烧录流程与原路径部署 API。下载成功依据设备执行日志与应用 UART 输出，未额外读取全片进行逐字节比对。

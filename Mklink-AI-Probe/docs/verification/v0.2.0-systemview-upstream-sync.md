## 行为变化

- duration 使用单调时钟；空闲超时以最后收到数据为起点，容忍短暂空读和读异常。
- 每个 Device 连接只有首会话可在先有数据后停流时自动恢复一次；后续会话
  与持续故障不进入重复恢复循环。恢复不延长 duration。
- 恢复时重建解析器，清除旧历史、统计和任务名等状态，并重新应用 CPU 时钟提示。
- 任务名解析无结果后停止继续为解析拆流；停止/重新启动失败保留真实原因。
- 状态接口暴露连接/会话代次、重试次数、原因和停止错误；GUI 显示恢复提示，
  新恢复通知清除失败突发的数据，同一恢复通知重复到达不再次清空。

# 0.2.0 仪表盘后台采集与 SVD 外设观察

日期：2026-09-05。范围为 `codex/v0.2.0-development` 源码服务和生产 GUI；不代表安装包或正式发布验收。

## 行为

- 仪表盘首次打开后保留实例与 DOM；切换串口助手、SuperWatch、RTT View，或者离开仪表盘进入配置页，不销毁采集组件、清空缓冲或发送停止命令。
- 单探针桥接流仍互斥。启动另一桥接功能返回 `PROBE_BUSY` 并提示先停止当前功能，不再隐式停止另一个用户采集。独立 UART 可同时运行。
- SuperWatch 左侧分为“程序变量”和“芯片外设”。保留原有 AXF、变量观察和手动分图功能，不自动分离 GPIO 通道。
- 型号输入支持联想选择与键盘操作；下方显示对应 SVD 文件名，例如 `STM32F103xx.svd`。根据已安装 Pack 的 PDSC 设备继承关系解析实际 SVD，不以型号前缀猜文件，不自动下载 Pack。
- 加载外设无需 AXF，改变芯片只替换外设目录与已选外设，不删除程序变量；运行中拒绝改变芯片。设备重新连接后清除旧外设选择，避免沿用另一芯片地址。
- 寄存器和位域为只读观察。过滤 SVD 标记的只写寄存器与读取副作用；8/16/32 位对齐读取，外设不同地址不跨间隙合并。同一寄存器与位通道共享读取，先按整数提取位域，再转换为波形数值。

## 真机方法

Windows、真实 Edge 浏览器、MKLink V4、STM32F103RE。沿用现有 RT-Thread 测试固件；本轮不修改/下载固件，不改变供电。测试工程已配置 GPIOB.12 每 100 ms 翻转。

使用实际安装的 `Keil.STM32F1xx_DFP@2.4.1`，选择 `STM32F103RE`，解析 `SVD/STM32F103xx.svd`，得到 4876 个寄存器/位观察项，过滤 70 个不适合读取的寄存器。GPIOB.12 对应 `GPIOB.IDR` 的 bit 12。

浏览器运行生产构建，全部 HTTP、WebSocket、Worker 数据来自真实服务和硬件，无传输模拟。先并行启动 UART 和 RTT，再明确停止 RTT、重新连接并启动 SuperWatch；四通道为程序计数变量、GPIOB.12、GPIOB.IDR、GPIOB.ODR。两阶段均切换仪表盘子页及顶层配置页，核对后台状态、组件身份、网络停止请求、Worker 缓冲、UART 文本序号与位值。最后手动分离 GPIOB.12 并检查方波，再停止并释放接口。

原始本地记录保存在忽略目录 `.build/reports/dashboard-peripheral-hil-20260905`，不提交固件、Pack、设备标识、主机硬件路径或截图。

## 结果

- 最终完整浏览器 HIL 通过。UART 收到 10,047 条完整 `uart=...,DATA_1234` 文本，序号逐条加一；浏览器记录 5,703 个串口文本块和 748 个 RTT 文本块。两次切换配置页时 UART 接收持续约 5.2 kB/s。
- SuperWatch 约 1 kHz，最终浏览器缓冲 19,468 点，910 次显示摘要；观察到 GPIOB.12 的 0/1 两种状态，每份摘要均等于同帧 `GPIOB.IDR` 的 bit 12。混合程序变量和外设观察通过，手动分图后的方波已检查。
- 两阶段切页均未发送额外启动/停止请求，RTT、串口及 SuperWatch 组件身份不变，缓冲持续增长，页面 JavaScript 错误为零。所有 Worker 的 transport/backend dropped batches 为零。
- SuperWatch 后端本次会话完整解析 19,473 帧，CRC 错误、丢帧与固件丢样标志增量均为零；启动阶段解析器丢弃 74 字节。因此不宣称从启流首字节到结束绝对无损。
- RTT 运行时直接请求启动 SuperWatch 返回 409，RTT 仍运行；明确停止后可启动 SuperWatch。
- 最后停止 UART、断开设备，复核串口 `running=false`、RTT `running=false`、SuperWatch `stopped`、设备 `connected=false`。8765 最新源码服务保留，旧 8766 服务已关闭。
- GUI 全量 657 项通过，生产类型检查与构建通过。真机阶段发现并修复隐藏页面 DOM 被卸载、经典波形脚本加载后未重放连接状态的问题；最终 HIL 覆盖这些修复。
- Python 定向 289 项通过，覆盖外设解析/安全过滤/位提取、无 AXF 选芯片、保留程序变量、运行时拒绝换芯片、仪表盘资源冲突、流传输、符号目录、内存会话与性能。此前一个新增 API 测试的闭包 mock 安装顺序错误已修正后完整重跑。

## 边界

- 缓冲区有容量上限；本结论是切页不导致采集停止或缓冲重置，不代表无限历史保存。
- SWD 轮询反映采样时刻电平，可能漏掉短脉冲，不等同逻辑分析仪。GPIO 时钟由目标程序开启，IDR 为引脚输入电平，ODR 为输出锁存值。见 [ST RM0008](https://www.st.com/resource/de/reference_manual/cd00171190.pdf)。
- 厂商 SVD 未标注的读取副作用无法仅靠目录过滤判断；通用系列 SVD 也不证明每种封装都具备全部外设。依据 [CMSIS-SVD 寄存器属性](https://arm-software.github.io/CMSIS_5/SVD/html/elem_registers.html)，仍须以实际芯片手册为准。本轮只对上述 GPIO 做真机验证，未验证整个外设目录。
- 多通道共用纵轴时，0/1 位波形可能被大数值压平；用户可在图例中手动分图。按用户明确要求不自动分图。
- 本轮未重建桌面安装包，已安装的早期本地候选不包含这些源码更新；Mac/Linux 未做实机验证。上游 PR 按用户要求留到 0.2.0 开发完成后。

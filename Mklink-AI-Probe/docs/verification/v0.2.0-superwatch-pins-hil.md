# SuperWatch 常用变量与多关键词搜索验收

日期：2026-09-03。分支：`codex/v0.2.0-development`。

## 行为与安全边界

- 变量可单独置顶，也可批量“置顶已选”；常用变量区始终显示，可上下调整顺序。
- 收藏与采样互相独立：取消采样不删除收藏；取消收藏不删除正在选择的采样通道。
- 搜索支持英文/中文逗号、分号及换行，多个关键词按 OR 匹配；搜索只过滤下方目录。
- 收藏按工程存储在 `.mklink/superwatch_pins.json`，仅包含格式版本和有序符号路径，不持久化地址或自动启动采集。
- 当前 AXF 提供实际描述符；符号缺失或源失效时收藏保留但禁用。更新采用原子替换及单后端内的 revision 冲突检查，损坏配置不静默覆盖。
- 最多 128 个收藏。窄变量面板采用两行布局，避免排序按钮撑宽列表、遮住名称和采样勾选框。

## 真实浏览器与硬件

使用 Browser 插件控制实际 WebGUI 生产资源，与已连接的 MKLink V4 / STM32F103RE 测试工程配合；未模拟接口。本轮未烧写固件、写变量、改变保护或 VCC。

| 操作 | 结果 |
| --- | --- |
| 一次搜索计数、温度、转速三个真实符号 | 同时返回三个变量，可勾选并批量置顶 |
| 取消温度变量采样 | 已选数从 3 变成 2，收藏仍为 3 |
| 重新排序，切换为两个 PID 变量的中文逗号搜索 | 收藏保持显示，下方仅显示匹配结果 |
| 取消转速变量置顶 | 收藏数减少，已选采样数不变 |
| 恢复三个收藏并刷新页面 | 名称、顺序和当前后端选择可恢复，采集不自动启动 |
| 约 20 秒、1 ms 周期的三通道采集 | 收到 20,221 pts；页面约 997–1,000 Hz，transport drops 0，backend drops 0/0；停止后波形与末值保留 |
| 停止后断开、重连，再重新解析实际 AXF | 正常恢复连接，收藏重新绑定，显示重载提示，采集仍停止 |
| 窄面板截图检查 | 三个收藏名称、勾选、上下移和取消置顶可见，无收藏行水平溢出 |

本轮真机验证的是现有 AXF 的重新解析；不同编译地址及缺失符号由后端/组件测试验证，不将其冒充为本轮重新编译下载。此前物理地址移动的回归证据见 [文件重载 HIL](v0.2.0-macos-file-reload-hil.md)。

- 覆盖工程隔离、顺序和去重、无地址持久化、缺失符号/地址重绑定、配置损坏与写入失败保护、revision 冲突、页面重挂载、收藏与选择独立、多关键词过滤。

# 在线与脱机烧录页面切换修复

## 问题和原因

Web GUI 和桌面客户端共用 App.vue。用户点击脱机烧录后，URL 和导航高亮
更新，但内容仍停留在线烧录页；反向切换也会发生。

RouterView 内的动态组件带 v-if，却没有显式 key。编译器为该条件分支
生成相同的键，KeepAlive 因而将 OnlineFlashView 和 OfflineFlashView
视作同一个缓存项。真实 RouterView/KeepAlive 回归在旧代码中双向失败，
出现 `parentComponent.ctx.deactivate is not a function`，并保留错误页面。

修复使用 RouterView 插槽对应的页面路径作为缓存键，查询参数不导致重新
创建页面。保留在线、脱机各自的缓存及仪表盘原有常驻 DOM 行为。

  DOM 仍连接文档、页面 JavaScript 错误为零。测试后恢复频率设置。
- 用户当前内置浏览器也实测脱机→在线→脱机，显示正确内容。

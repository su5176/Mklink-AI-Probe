  snapshots; the UI explicitly distinguishes this from original-path tracking.

  receiver, preventing an incompatible invocation from falling back to a snapshot.
  This invocation is covered by a receiver-sensitive unit test; it is not proof
  that this was the specific cause of the user's report.
- Explicit symbol replacement now uses the shared exclusive probe-control guard
  to stop dependent capture before replacing symbols, matching source monitoring.
  No automatic flash or capture restart was introduced.

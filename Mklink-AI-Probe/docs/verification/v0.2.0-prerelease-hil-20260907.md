# v0.2.0 发布前 HIL（2026-09-07）

本轮验证对象为 V4 + STM32F103RE。用户已授权修改、编译、下载测试工程，以及在 3.3V 下加锁、解锁擦除并恢复。没有连接 Modbus 从站。基线 `52ff114` 已按授权推送 master；本轮新增修复为 `6a92b5e` 和 `fa8807b`。本地候选运行时显示 `0.2.0 / fa8807b4ac40`，不代表正式 Release。

## 修复及复测

- 测试固件的 UART 压力输出改用独立行缓冲直接写串口；波形任务主动让出 CPU，优先级低于 Finsh。此前终端命令不响应涉及任务饥饿，并非仅由接线或上位机发送造成。修正后重新编译，正常工程全量构建 0 错误、4 警告。
- 高吞吐切页暴露串口 WebSocket 的 64 批队列溢出。串口按 20ms / 4KiB 合批、订阅队列扩大至 256 批，并在持续流期间发送状态心跳；关闭时冲刷最后一批。新增测试覆盖忙事件循环、方向顺序和低速尾字节。
- 内嵌 RTT 语言切换移除不适用的旧端点请求，SystemView 复测没有此前的 HTTP 405 控制台错误。
- 主窗口关闭后显式退出 Tauri，避免托盘使无窗口进程继续驻留。候选程序及实际安装版均以原生窗口操作验证退出。

## 同源安装与最终设备状态

Skill 与生产 GUI 文件逐字节一致；公共 Skill 不含维护记忆、测试、构建技能或 AGENTS 文件。桌面后端与 Skill 内置算法资产一致，目录覆盖 7059 型号、2224 去重算法。实际安装的后端与构建后端一致；主程序除 Tauri 打包器写入的 NSIS 类型标记外与构建程序一致。CLI/MCP 调用来自已安装 Skill，不是依靠源码目录导入。

原始全片备份以及修改前源码、AXF/HEX/BIN 均保留在本地忽略目录。安全恢复验证之后，目标重新写入修复后的正常测试程序；因此最终运行修复程序，不声称仍运行原始 Flash 映像。正常工程的 AXF、HEX、BIN 已重新生成，独立回读验证应用与 HEX 一致，BIN 与 HEX 内容一致，目标未保护。最后一轮原生 SuperWatch 测试后停止并断开，复核 UART 401 行连续，两串口均可重新打开且已释放；本轮创建的临时 USB 脚本已归档移除，原 USB 文件保留。桌面保留停止后的曲线供用户查看。

## 原生桌面 SuperWatch 17 通道复测

此轮选择通道、加载外设、开始、暂停显示、恢复、切换串口助手/RTT View、返回、导出 CSV、停止和断开均使用 Windows computer-use。后端状态和导出 CSV 仅用于独立核对，不代替界面操作。16 个程序通道为 `superwatch_ch00` 至 `superwatch_ch15`，外设通道为 SVD 定义的 GPIOB.IDR bit12，显示名 `GPIOB.12`。

- 累计 324112 组完整采样，结束前实际速率 996.26Hz。读取错误、CRC 错误、固件丢样标志、解析丢帧及传输丢样均为 0。启动解析器丢弃 60 字节，因此不表述为原始字节全程无损。
- CSV 导出 200000 行、17 个数据通道，时间范围 37.659004–237.658010 秒。全部值有限、全部通道有变化，时间戳严格递增；中位采样间隔 1ms，最大间隔 1.194ms。
- GPIO 仅有 0/1 两种值，记录 2007 次跳变，中位半周期 99.997ms；变量波形和 GPIO 方波均在桌面可见。
- 暂停按钮冻结图表显示，后台采集继续；恢复显示后实时曲线更新。切到串口助手与 RTT View 时，读取计数分别为 192189 和 211423，仍为 running；返回后曲线恢复绘制，直到主动停止才结束采集。
- 原始 CSV 与状态记录位于本轮本地报告目录的 `native-superwatch-*` 文件；用户固件和原始采样不提交仓库。

## 尚未关闭的限制

- RTT 启动偶发报告控制块不存在，显式断开重连后可启动。原始命令应答记录发现启动描述与 RTT 有效负载交错，作为后续固件路由时序排查线索；本轮没有修改或下载探针固件。
- 停止 RTT 后第一条 UART help 曾出现 `RTTView.stop(` 前缀进入目标 shell；第二次 help 正常。需要继续检查探针命令识别与下行转发，不能用重复发送掩盖为完全通过。
- 高速 USB 不稳定引发的设备识别问题按用户要求暂缓；本轮没有以普通传输成功宣称其根因已解决。
- 未覆盖物理 Modbus、其他芯片/探针组合、Mac/Linux、现场 Agent 实际跨主机链路；这些能力不能从单块 F103 的结果外推。
- NSIS 为未签名本地候选，没有发布标签、更新指针或正式安装包 Release。

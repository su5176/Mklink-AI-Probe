## 本轮改动

脱机配置在全片擦除选项旁持续说明：默认按扇区擦除，通常无需全片擦除；全片擦除显著增加烧录时间。勾选后提示变为警示色，取消后恢复。中英文一致，保持原有默认值、确认流程与实际擦除逻辑。

用户报告 XMC4800 开启全片擦除导致执行延长。本轮是使用提示改进，没有以 STM32 测试证明 XMC4800 串口读取错误的根因，也没有将该错误宣称修复。
